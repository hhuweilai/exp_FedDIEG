## 2. 自动结论判定

- 覆盖的 ρ：0.00, 0.50, 0.80, 0.95
- ① 兴趣变化造成的 NDCG 落差（drift - stable，正 = 变化组更差）：ρ0.00:-0.0129±0.0121(显著,n=3); ρ0.50:-0.0132±0.0078(显著,n=3); ρ0.80:-0.0104±0.0131(不显著,n=3); ρ0.95:-0.0186±0.0185(显著,n=3)
- ② 恢复速度是否随 ρ 单调变慢（ndcg_lag_recover_90）：ρ0.00:60/ρ0.50:63/ρ0.80:60/ρ0.95:60；最慢 ρ=0.50，跨度 3 轮
- ③ 变化前最优 ρ vs 变化后最优 ρ：pre 最优 ρ=0.95，post 最优 ρ=0.50（不同 ρ → 存在权衡，自适应有意义）
- ④ 固定 ρ=0.00 是否已经足够好（不需要自适应）：没有 ρ 明显优于它 → 直接把 ρ 调小即可，自适应机制的收益空间很小
- ⑤ 旧兴趣同伴边权占比的半衰期是否随 ρ 变长：ρ0.00:10/ρ0.50:10/ρ0.80:10/ρ0.95:10

**部分成立：兴趣变化确实造成下降，但没有证据表明固定 EMA 让它恢复得更慢（任务书停止信号 2：固定 EMA 已能适应）**


## 3. 读图提示

- 横轴 0 是「兴趣变化前的最后一轮」；0 的右侧才是变化之后。
- 实线 = 兴趣变化组，虚线 = 活动量匹配的稳定对照组。真正的「漂移代价」应看 0 右侧两条线的**间距**，而不是实线自身的高低。
- 若 4 条实线在 0 右侧几乎重合，说明固定 EMA 的取值对推荐性能没有可见影响（任务书停止信号 2）；此时结合 `val02_fig_edge_adjust.png` 判断是不是图权重太小。
